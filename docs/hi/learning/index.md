# सीखने का रास्ता

वेबसाइट खोलें और पेज बनाने वाला कोड पढ़ें। छह अभ्यास कार्ड, भाषा, कैश, ऐनिमेशन, लेखों के मेटाडेटा और संसाधनों को जाँचते हैं।

1. सभी भाषाओं में कार्ड सुधारें; ID और लिंक बचाएँ। सर्वर HTML और Hydration के बाद DOM की तुलना करें।
2. भाषा को मेन्यू, लेख, `lang`, `dir` और sitemap तक खोजें; भाषा बदलते समय query और URL का खंड बचे।
3. असली ETag, खाली `304` और भाषा व origin के अनुसार कैश का अलगाव जाँचें।
4. विराम, दृश्यता, बैकग्राउंड टैब और कम ऐनिमेशन जाँचें तथा सामान्य व्यवहार बचाएँ।
5. लेख और भाषा बदलकर canonical, शेयर मेटाडेटा और दिशा जाँचें।
6. दृश्य का एक चरण बदलें और सोर्स, मूल फ़ाइल व हैश जाँचें। build को `/harness-source/` नहीं माँगना चाहिए।

संदर्भ बदलने से पहले डेटा, इंटरैक्शन और चित्र की तुलना करें। रिपोर्ट को वर्ज़न वाले सोर्स से बाहर रखें। पाठक की समस्या, ज़िम्मेदार कोड, जाँच का परिणाम और प्रमाण की सीमा बताएँ। स्थानीय चित्र मूल वेबसाइट से हर पिक्सेल का मेल साबित नहीं करता।

```sh
pnpm analyze
pnpm perf:repeat
pnpm test:visual
```

# प्रोजेक्ट का परिचय

यह रिपॉज़िटरी Next.js और React से DeepSeek Harness वेबसाइट दोबारा बनाती है। दस्तावेज़ पेज की संरचना, कंपोनेंट, भाषा, ऐनिमेशन और परीक्षण समझाते हैं। लेख VitePress से बनते हैं।

पाठक पहले उत्पाद समझता है, चार डेमो देखता है, विवरण खोलता है और अगला कदम चुनता है। सर्वर से मिला कंटेंट, असली लिंक और HTML के विवरण JavaScript के बिना भी उपयोगी रहते हैं।

`src/i18n/locales.json` भाषा, रास्ते, दिशा और मेटाडेटा का साझा स्रोत है। `/harness/` चीनी प्रवेश बना रहता है; `/docs/` अंग्रेज़ी खोलता है। हर भाषा में वही पाँच अध्याय हैं।

पढ़ने योग्य कंपोनेंट रखरखाव आसान करते हैं। सफल build अपने आप दृश्य समानता, स्वाभाविक अनुवाद या असली डिवाइस पर प्रदर्शन साबित नहीं करता। इनके लिए अलग जाँच चाहिए।

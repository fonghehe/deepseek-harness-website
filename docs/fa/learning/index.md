# مسیر یادگیری

سایت را باز کنید و کدی را که صفحه را می‌سازد بخوانید. شش تمرین، کارت‌ها، زبان‌ها، کش، پویانمایی، فرادادهٔ مقاله‌ها و منابع را بررسی می‌کنند.

1. کارت را در همهٔ زبان‌ها بهتر کنید؛ ID و پیوندها را نگه دارید و HTML سرور را با DOM پس از Hydration مقایسه کنید.
2. زبان را تا منو، مقاله، `lang`، `dir` و sitemap دنبال کنید؛ query و بخش URL در تغییر زبان حفظ شوند.
3. با ETag واقعی، `304` خالی و جداسازی کش زبان و origin را بیازمایید.
4. توقف، دیده‌شدن، زبانهٔ پس‌زمینه و کاهش حرکت را با حفظ رفتار معمول بررسی کنید.
5. مقاله و زبان را عوض کنید و canonical، فرادادهٔ اشتراک و جهت را بسنجید.
6. یک مرحلهٔ صحنه را تغییر دهید و منبع، ورودی و هش را بررسی کنید. ساخت نباید `/harness-source/` را درخواست کند.

پیش از تغییر مرجع، داده، تعامل و تصویر را مقایسه کنید. گزارش را بیرون منابع نسخه‌بندی‌شده نگه دارید. مشکل بازدیدکننده، کد مسئول، نتیجهٔ آزمون و محدودیت شاهد را توضیح دهید؛ تصویر محلی، تطابق پیکسلی با اصل را ثابت نمی‌کند.

```sh
pnpm analyze
pnpm perf:repeat
pnpm test:visual
```

| اصطلاح            | معنی                                 |
| ----------------- | ------------------------------------ |
| SSR               | رندر سمت سرور                        |
| Hydration         | Hydration: افزودن تعامل به HTML سرور |
| Reduced motion    | ترجیح کاهش پویانمایی                 |
| RTL               | چیدمان راست به چپ                    |
| Visual regression | آزمون رگرسیون بصری                   |
| Resource budget   | بودجهٔ منابع                         |

# نمای کلی پروژه

این مخزن سایت DeepSeek Harness را با Next.js و React بازسازی می‌کند. مستندات ساختار صفحه‌ها، اجزا، زبان‌ها، پویانمایی و روش آزمون را توضیح می‌دهند. مقاله‌ها با VitePress ساخته می‌شوند.

بازدیدکننده ابتدا محصول را می‌شناسد، چهار نمایش را می‌بیند، جزئیات را باز می‌کند و اقدام بعدی را انتخاب می‌کند. محتوای سرور، پیوندهای واقعی و جزئیات HTML بدون JavaScript هم مفیدند.

`src/i18n/locales.json` زبان‌ها، مسیرها، جهت و فراداده را هماهنگ می‌کند. `/harness/` ورودی چینی را نگه می‌دارد؛ `/docs/` انگلیسی را باز می‌کند. همهٔ نسخه‌ها همان پنج فصل را دارند.

اجزای خوانا نگهداری را آسان می‌کنند. ساخت موفق، تطابق بصری، ترجمهٔ طبیعی یا عملکرد دستگاه واقعی را ثابت نمی‌کند؛ هرکدام بررسی جداگانه می‌خواهد.

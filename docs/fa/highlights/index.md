# روش‌های فرانت‌اند

## اطلاعات و کنترل

از فایده به نمونه، جزئیات و اقدام برسید. پیوند واقعی و کنترل HTML به کار ببرید. صفحه‌کلید، Escape، بازگشت فوکوس، منوی باریک و استفاده بدون JavaScript را بررسی کنید.

## زبان و SEO

واژه‌نامه، برچسب دسترس‌پذیر، فراداده، ناوبری و مقاله باید هماهنگ باشند. RTL به CSS منطقی نیاز دارد؛ کد LTR می‌ماند. Canonical، hreflang، دادهٔ ساخت‌یافته و فرادادهٔ اشتراک باید حتی پس از ناوبری کلاینت به صفحهٔ فعلی مربوط باشند.

## منابع و شواهد

اجزا، شیدر، CSS، Markdown و ورودی ثابت منابع قابل نگهداری‌اند. `tests/fixtures/assets.json` یکپارچگی را می‌سنجد؛ `.next`، `public/docs` و گزارش‌ها خروجی‌اند. برند و مجوز در `NOTICE.md` آمده است.

حجم داده، LCP، CLS و زمان مسدودسازی را تکراری و روی دستگاه واقعی بسنجید. baseline را برای پنهان کردن پسرفت عوض نکنید. آزمون محلی، CI دوردست و بازبینی انسانی زبان یا دسترس‌پذیری شواهد متفاوتی می‌دهند.

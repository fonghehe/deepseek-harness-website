# Вимоги до сайту

Перевірте, чи можна читати вміст без анімацій. Довгі назви, меню й команди мають уміщатися на вузькому екрані. Після гідратації перевірте клавіатуру, паузу, копіювання та посилання.

Кожна мова потребує словника, карток, доступних підписів, метаданих, навігації, описів і п’яти статей. Зберігайте параметри й теги rich text. Frontmatter має відповідати `docs/descriptions.json`.

Перед браузерними тестами зберіть виробничу версію й використовуйте вільний порт. З’ясуйте причину помилки контрольної суми перед оновленням ресурсів. Сервер має отримати весь `public`; перевірте `SITE_URL`, англійський вхід, 404, sitemap, favicon, динамічні модулі й кеш. Для Pages перевірте також префікс шляхів.

Огляньте вузький екран, RTL, змішані напрямки тексту, фокус, читач екрана й зменшення анімації. Запишіть пристрій і браузер. Переклади надалі потребують перевірки носіями мови.

```sh
pnpm verify
E2E_PORT=3101 pnpm test:e2e
pnpm verify:full
SITE_URL=https://example.github.io/repository/ pnpm build:pages
SITE_URL=https://example.github.io/repository/ pnpm check:pages
```

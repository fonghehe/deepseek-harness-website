# Практики фронтенду

## Інформація та керування

Почніть із користі, далі покажіть приклад, подробиці та дію. Використовуйте справжні посилання й HTML. Перевіряйте клавіатуру, Escape, повернення фокуса, вузькі меню й роботу без JavaScript.

## Мови та SEO

Словники, доступні підписи, метадані, навігація й статті мають бути узгоджені. RTL потребує логічних властивостей CSS; код залишається LTR. Canonical, hreflang, структуровані дані й метадані поширення повинні відповідати поточній сторінці також після клієнтської навігації.

## Джерела та докази

Компоненти, шейдери, CSS, Markdown і статичні вхідні ресурси зберігаються як джерела. `tests/fixtures/assets.json` перевіряє цілісність; `.next`, `public/docs` і звіти є результатами. Бренди й ліцензії описані в `NOTICE.md`.

Повторюйте заміри обсягу даних, LCP, CLS і часу блокування, перевіряйте справжні пристрої. Не змінюйте baseline для приховування регресії. Локальні тести, віддалений CI та ручна перевірка мови або доступності дають різні докази.

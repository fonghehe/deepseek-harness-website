# Огляд проєкту

Цей репозиторій відтворює сайт DeepSeek Harness за допомогою Next.js і React. Документація описує сторінки, компоненти, мови, анімації та тести. Статті збирає VitePress.

Відвідувач знайомиться з продуктом, переглядає чотири демонстрації, розкриває подробиці й обирає наступну дію. Серверний вміст, справжні посилання й елементи HTML залишаються корисними без JavaScript.

`src/i18n/locales.json` об’єднує мови, шляхи, напрямок і метадані. `/harness/` зберігає китайський вхід; `/docs/` відкриває англійську версію. Кожна документація має ті самі п’ять розділів.

Читабельні компоненти полегшують супровід. Успішне збирання не доводить візуальної точності, природності перекладу чи швидкості на справжніх пристроях; це потребує окремих перевірок.

# Навчальний маршрут

Відкрийте сайт і знайдіть код, що створює сторінку. Шість вправ стосуються карток, мов, кешу, анімацій, метаданих статей і ресурсів.

1. Поліпшіть картку всіма мовами, збережіть ID й посилання та порівняйте серверний HTML із DOM після гідратації.
2. Простежте мову до меню, статті, `lang`, `dir` і sitemap; збережіть query та фрагмент під час перемикання.
3. Справжнім ETag перевірте порожню `304` й розділення кешу за мовою та origin.
4. Перевірте паузу, видимість, фонову вкладку й зменшення анімації, зберігши звичайну поведінку.
5. Змініть статтю та мову й перевірте canonical, поширення та напрямок.
6. Змініть одну фазу сцени й перевірте джерела, ресурси та хеші. Збірка не повинна запитувати `/harness-source/`.

Порівнюйте дані, взаємодію та знімки до оновлення еталонів. Звіти тримайте поза версійованими джерелами. Поясніть проблему відвідувача, відповідальний код, результат тесту й межі доказу; локальні знімки не доводять збігу піксель у піксель з оригіналом.

```sh
pnpm analyze
pnpm perf:repeat
pnpm test:visual
```

| Термін            | Значення                                           |
| ----------------- | -------------------------------------------------- |
| SSR               | Серверний рендеринг                                |
| Hydration         | Гідратація: додавання взаємодії до HTML із сервера |
| Reduced motion    | Налаштування зменшення анімації                    |
| RTL               | Розміщення справа наліво                           |
| Visual regression | Тести візуальних регресій                          |
| Resource budget   | Бюджет ресурсів                                    |

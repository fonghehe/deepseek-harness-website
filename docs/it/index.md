# Panoramica del progetto

Questo repository ricrea il sito DeepSeek Harness con Next.js e React. La documentazione descrive pagine, componenti, lingue, animazioni e test. Gli articoli sono generati con VitePress.

Il visitatore conosce il prodotto, osserva quattro dimostrazioni, apre le schede di dettaglio e sceglie un’azione. Contenuto del server, collegamenti reali ed elementi HTML espandibili restano utili senza JavaScript.

`src/i18n/locales.json` riunisce lingue, percorsi, direzione e metadati. `/harness/` conserva l’ingresso cinese, mentre `/docs/` apre l’inglese. Tutte le edizioni della documentazione hanno gli stessi cinque capitoli.

Componenti leggibili facilitano la manutenzione. Una compilazione riuscita non dimostra fedeltà visiva, qualità linguistica o prestazioni sui dispositivi reali: servono verifiche dedicate.

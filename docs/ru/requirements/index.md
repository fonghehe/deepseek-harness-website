# Требования к сайту

Используйте этот список при проверке изменений и подготовке публикации. Выбирайте проверки по изменённым файлам и поведению.

## Критерии

| Область        | Ожидаемый результат                                             |
| -------------- | --------------------------------------------------------------- |
| Информация     | Тема и действие понятны без всех анимаций                       |
| Узкий экран    | Длинные подписи, меню и команды без переполнения                |
| Взаимодействие | Ссылки после гидратации, клавиатура и детали без JS             |
| Языки          | Все языковые версии с согласованными путями, направлением и SEO |
| Метаданные     | Canonical и sharing соответствуют текущей статье                |
| HTTP           | Нет смешивания origin/языка; 304 без тела                       |

Порядок чтения, смешанную пунктуацию и формулировки проверяют вручную.

## Что коммитить

Компоненты, хуки, CSS, Markdown и статические ресурсы хранятся в системе контроля версий. `pnpm build` генерирует JavaScript и CSS; `.next` и `public/docs` исключены из Git. Проверки по `tests/fixtures/assets.json` подтверждают целостность ресурсов и предотвращают возврат захваченного HTML или чужого кода приложения.

`.next`, `public/docs`, кеши, отчёты и установленные пакеты — генерируемый вывод. Общие настройки должны быть переносимыми, секреты и личные настройки остаются локальными. Ignore не заменяет права доступа.

## Проверка изменения

```sh
pnpm verify
E2E_PORT=3101 pnpm test:e2e
```

Сначала production-build, затем нужные браузерные сценарии на свободном порту. Синхронизируйте descriptions и frontmatter всех языковых версий. Не заменяйте checksum до выяснения причины расхождения.

## Перед публикацией

Документы строятся до Next.js, весь `public` включается в доставку. Проверьте `SITE_URL`, английский по умолчанию, языки, 404, sitemap, favicon, демонстрации и динамические чанки. Headers кеша различаются по категориям. Локальный успех, удалённая CI и production-проверка — отдельные свидетельства.

## Производительность и обслуживание

Сопоставляйте payload, LCP, CLS и блокировки. Серверный кеш не удаляет исполнение JS. Не перезаписывайте baseline ради прохождения; расширение статьи требует явного рассмотрения бюджета. При обновлении ресурсов и анимаций проверяйте связанные компоненты и CSS, происхождение файлов, контрольные суммы и сохранение прежнего поведения.

Продолжайте [Учебный маршрут](../learning/).

Только китайский показывает WeChat QR; остальные языки ведут на https://x.com/deepseek_ai.

## Ручная проверка

Проверьте клавиатуру, Escape и возврат фокуса в меню, а также объявление копирования программой чтения с экрана. На телефоне проверьте прокрутку и фазы анимации. Повторите для арабского языка с длинными строками и смешанным направлением. Запишите устройство, браузер, настройки движения и доказательства. Переводы требуют проверки носителем языка.

```sh
pnpm verify:full
SITE_URL=https://example.github.io/repository/ pnpm build:pages
SITE_URL=https://example.github.io/repository/ pnpm check:pages
SITE_URL=https://example.github.io/repository/ pnpm perf:pages
```

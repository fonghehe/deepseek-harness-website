# Обзор

В этом репозитории сайт DeepSeek Harness воссоздан на Next.js и React. Документация описывает страницы, компоненты, языки, анимации и тесты. Статьи собираются с помощью VitePress.

Главная версия — английская, `/docs/` открывает её напрямую. Переводы дополняют те же пять глав. Существующий китайский вход сайта `/harness/` сохраняется отдельно.

## Путь посетителя

Первый экран объясняет тему и действие, четыре интерактивных примера углубляют понимание, дополнительные карточки раскрывают детали, а блок для разработчиков предлагает следующий шаг. Расширение сохраняет прежние демонстрации и визуальную логику. Без JavaScript остаются полезными заголовки, ссылки, дополнительные подробности и вход в документацию.

## Ответственность технологий

| Слой               | Назначение                          | Источник                 |
| ------------------ | ----------------------------------- | ------------------------ |
| Next.js            | HTTP, HTML, перенаправления, SEO    | `src/app/`               |
| React              | JSX / SSR / hydration               | `src/components/`        |
| Поддерживаемый код | Переводы, расширение и кеш          | `src/lib/`, `src/i18n/`  |
| VitePress / Vue    | Статьи, поиск, навигация документов | `docs/.vitepress/`       |
| Проверки           | Типы, ресурсы, языки, браузеры      | `tests/tools/`, `tests/` |

Сайт создаётся из React-компонентов, хуков и CSS этого репозитория. Next.js отвечает за серверный рендеринг (SSR) и гидратацию. Захваченный HTML и скомпилированное приложение оригинального сайта не загружаются. Изображения бренда, шрифты, иконки файлов и QR-код WeChat используются как статические ресурсы.

## Сильные стороны и ограничения

Тёмные поверхности, типографика, отступы и существующие ресурсы сохраняют целостность. Favicon чёрный. Общий реестр связывает маршруты, направление и метаданные. Затраты на рендеринг на мобильных устройствах и поддержка анимаций требуют дальнейших измерений и проверок. Автоматизация не доказывает качество перевода или доступность для всех вспомогательных средств.

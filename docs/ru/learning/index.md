# Учебный маршрут

Откройте сайт и найдите код, который создаёт страницу. Шесть упражнений посвящены карточкам, языкам, кешу, анимациям, метаданным статей и ресурсам.

## Порядок чтения

Откройте английскую и арабскую версии сайта в узком окне. Проверьте управление с клавиатуры, настройку уменьшения анимации и работу без JavaScript. Затем изучите реестр языков, CSS и страницы для разных языков. Проследите маршрутизацию, рендеринг, HTML, SEO и кеширование. Конфигурация VitePress, Vue-тема и маршрут документации помогут понять, что выполняется при сборке, на сервере и в браузере.

## Упражнение 1: Общая карточка

Улучшите текст существующей карточки на всех поддерживаемых языках, сохранив её ID и ссылки. Сравните серверный HTML с DOM после гидратации. Проверьте раскрываемые элементы HTML, разметку RTL и четыре существующие демонстрации. Сервер и клиент должны по-прежнему использовать один шаблон.

## Упражнение 2: Языковой контракт

Проследите путь японской и арабской версий от реестра до маршрутов, `lang`, `dir`, подписей, документов и ссылок на другие языки. При переключении должны сохраняться параметры запроса, фрагмент URL и текущая статья. Опишите, какие изменения потребуются для нового языка; добавлять его ради упражнения не нужно.

## Упражнение 3: Разделение кеша

```sh
curl -i http://localhost:3100/docs/en/architecture/
curl -i -H 'If-None-Match: W/"COPY_THE_RETURNED_HASH"' http://localhost:3100/docs/en/architecture/
```

Повторите запрос с ETag из полученного ответа и проверьте, что сервер возвращает `304` без тела. Другая языковая версия и другой хост предпросмотра при незаданном `SITE_URL` должны получать собственные canonical URL и ETag.

## Упражнение 4: Ошибка анимации

При включённом уменьшении анимации первый экран должен оставаться видимым, а не застывать с начальным значением opacity. Объясните роль видимости элемента, активности вкладки, ограничения 30fps и DPR. Проводите замеры в одинаковых условиях и сохраняйте удобство обычного взаимодействия при оптимизации показателей.

## Упражнение 5: SEO после перехода

Согласуйте описания с данными frontmatter и переключите статью и язык. Проверьте canonical URL, метаданные для публикации ссылок и направление текста. Объясните, как удаляются прежние метаданные и отменяются обновления, которые уже не соответствуют текущей странице.

## Упражнение 6: компоненты и ресурсы

Прочитайте `capability-demos.tsx`, `use-demo-scene.ts` и `assets.json`. Измените одну фазу анимации, сохранив паузу и управление по видимости. Обновляйте хеш ресурса только при изменении самого файла. Убедитесь, что сгенерированные чанки не запрашивают файлы из `/harness-source/`.

## Представление результата

Опишите проблему посетителя, отвечающий за неё код, результаты проверок и оставшиеся ограничения. Разделите собственную реализацию и дизайн демонстраций исходного сайта; укажите нагрузку на мобильных устройствах и необходимые ручные проверки. Запустите `pnpm verify`, соответствующие браузерные тесты и замеры производительности. Сопоставьте результат с главой [«Архитектура»](../architecture/).

## Проследить улучшение полностью

Найдите длительную задачу в указанных ниже файлах, внесите небольшое изменение и сравните объём данных, взаимодействия и снимки. Храните отчёты вне версионируемых исходников. Проверяйте различия до обновления эталона; локальные снимки не доказывают точное совпадение с оригинальным сайтом.

```sh
pnpm analyze
pnpm perf:repeat
pnpm test:visual
```

| Термин            | Значение                                              |
| ----------------- | ----------------------------------------------------- |
| SSR               | Серверный рендеринг                                   |
| Hydration         | Гидратация: добавление интерактивности к HTML сервера |
| Reduced motion    | Настройка уменьшения анимации                         |
| RTL               | Разметка справа налево                                |
| Visual regression | Тестирование визуальных регрессий                     |
| Resource budget   | Бюджет ресурсов                                       |

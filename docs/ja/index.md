# 概要

このリポジトリは Next.js と React で DeepSeek Harness のサイトを再現しています。文書ではページ構成、コンポーネント、言語、アニメーション、テスト方法を説明します。文書の構築には VitePress を使います。

英語が基本版で、`/docs/` は英語へ直接移動します。ほかの言語版も同じ五章で構成されています。サイトの中国語版は、これまでどおり `/harness/` から開けます。

## 訪問者の理解を段階的に支える

ヒーローで主題と行動を示し、四つの対話型デモで理解を深め、追加カードで詳細を開き、開発者向け領域で次の行動につなげます。既存デモは維持され、拡張はその視覚的な文脈に加わります。JavaScript を無効にしても、見出し、リンク、追加の詳細とドキュメントへのリンクが読めることが重要です。

## 技術の責任範囲

| 層                 | 役割                               | 読む場所                 |
| ------------------ | ---------------------------------- | ------------------------ |
| Next.js            | HTTP、文書配信、SEO、リダイレクト  | `src/app/`               |
| React              | JSX / SSR / hydration              | `src/components/`        |
| 維持するモジュール | 翻訳、追加 HTML、キャッシュ        | `src/lib/`、`src/i18n/`  |
| VitePress / Vue    | 静的記事、検索、文書ナビゲーション | `docs/.vitepress/`       |
| 品質               | 型、リソース、言語、ブラウザー検証 | `tests/tools/`、`tests/` |

サイトは本リポジトリで管理する React コンポーネント、Hook、CSS から構築します。Next.js がサーバーサイドレンダリング（SSR）とハイドレーションを担当します。元サイトから取得した HTML やコンパイル済みアプリは読み込まず、ブランド画像、フォント、ファイルアイコン、WeChat の QR コードなどを静的リソースとして利用します。

## 強みと限界を同時に読む

統一された暗い画面、フォント、余白、黒い favicon と既存リソースが視覚的な連続性を保ちます。言語は文言だけでなく経路、方向とメタデータを共有します。一方、モバイルでの描画負荷や、アニメーションの保守には継続的な検証が必要です。自動テストは翻訳の自然さやすべての補助技術を保証しません。

# フロントエンドの特徴

ページの構成、操作、言語、描画について、実装箇所と確認方法を説明します。

## 1. 情報の順序

見出し、実例、詳細、行動を順に配置し、走り読みと深い理解を両立します。アニメーションより先に訪問者の疑問を整理する練習になります。

## 2. 小さい拡張境界

既存デモを維持し、共通 JSON の内容を React コンポーネントで描画して追加します。ページ全体を複製せず視覚的な連続性を保つ方法です。

## 3. ブランドリソースの再利用

黒い favicon、フォント、アイコンと画像をローカル配信します。出典と容量の両方を点検し、上流資産を自作と主張しません。

## 4. 多言語対応を一元管理

登録表が経路、ラベル、方向と SEO を駆動します。キーと変数の検証を、表現や改行の人手確認と組み合わせます。

## 5. 実際に機能する RTL

論理 CSS、メニュー位置と LTR コードを一緒に確認します。390px の アラビア語 検証は、単なる左右反転では不十分なことを示します。

## 6. 段階的な強化

HTML 標準の折りたたみ要素 と実リンクは JavaScript がなくても使えます。Escape、外側クリック、フォーカスと URL 保持だけを強化します。

## 7. SSR とハイドレーションの一致

言語を検証したページが共通 LandingPage を呼び、辞書を props として渡します。サーバーとクライアントは同じ JSX を使います。RichText は許可した書式だけを解釈し、任意 HTML を注入しません。ルートグループのルートレイアウトが lang と dir をサーバーで設定します。

## 8. 動きのライフサイクル

`use-demo-scene.ts` が表示状態、タブ、動きを減らす設定、一時停止をまとめて判定します。CSS は停止位置を保持します。Three.js は画面外で停止し、終了時に GPU リソースを解放します。詳しくは[アーキテクチャ](../architecture/)を参照してください。

## 9. 配信と結び付く SEO

canonical、alternate、共有メタデータをサーバーで生成し、文書移動後も更新します。地域を指定しないアラビア語 に架空の地域 OG locale を割り当てません。

## 10. 正しさを守るキャッシュ

`website-metadata.ts` は Next.js Metadata API を使い、`SITE_URL` またはプレビューのリクエスト元から URL を決定します。地域を指定しないアラビア語に、架空の地域コードは付けません。VitePress 記事のキャッシュはオリジンと記事ごとに分離し、最大 128 件を 5 分間保持します。失敗した描画結果は除去し、弱い ETag が一致した場合は本文のない `304` を返します。

## 11. リソースの監査

React、Hook、CSS、Markdown と静的リソースをバージョン管理します。JavaScript と CSS は `pnpm build` で生成し、`.next` と `public/docs` は Git の管理対象から除外します。`tests/fixtures/assets.json` に基づくチェックで静的リソースの整合性を確認し、取得した HTML や元サイトの実行コードが再導入されるのを防ぎます。

## 12. 動作に対応する品質管理

Oxlint、Oxfmt、Playwright、axe と Lighthouse の用途を分けます。テスト数ではなく、壊れる境界に証拠があるかを評価します。

## 残る課題

コンポーネントのソースを管理することは読みやすさを改善しますが、視覚一致、全操作とモバイル性能はブラウザーで別途確認します。歴史的レポートは旧実装の値です。人手で翻訳、フォーカスと混在方向を確認します。

## 計測に基づく性能改善

装飾はフォントとヒーローの表示時のアニメーション後、描画とアイドル処理を経て初期化します。影響が常にゼロの flow-map 分岐は同じ出力を保って除去しました。フレーム計数は明示的な分析だけで有効です。画面外とバックグラウンドでの停止、30fps、動きを減らす設定、GPU の解放を維持します。Node と Pages を別々に計測し、複数回の測定と実機で評価します。

- `src/components/graphics/schedule-scene.ts`, `fluid-shaders.ts`
- `src/components/graphics/particle-field.tsx`, `tile-scene.ts`
- `tests/tools/audit-performance.mjs`, `tests/fixtures/performance-budgets.json`

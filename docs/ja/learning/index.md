# 学習ガイド

まずページを開き、対応するソースを読みます。六つの実習でカード、言語、キャッシュ、アニメーション、文書のメタデータ、リソースを変更・確認します。

## 読む順序

まず英語版とアラビア語版を狭い画面で開き、キーボード操作、動きを減らす設定、JavaScript を無効にした状態を確認します。次に言語登録、CSS、言語ごとのページ構成を読み、ルート、描画処理、SEO とキャッシュをたどります。最後に VitePress の設定、Vue テーマ、文書配信ルートを読み、静的生成とサーバー・クライアントそれぞれの処理を区別します。

## 実習一：共通の描画処理でカードを変更

既存カードの文言をすべての言語版で改善し、ID とリンクを保持します。初期応答とハイドレーション後の内容、アラビア語、HTML 標準の詳細表示と元のデモを確認します。クライアント用の別テンプレートは作りません。

## 実習二：多言語対応を一通り調べる

日本語版とアラビア語版について、言語登録から経路、`lang`、`dir`、ラベル、文書、代替言語へのリンクまでをたどります。言語を切り替えてもクエリー、URL フラグメント、現在の記事が保持されることを確認し、新しい言語の追加に必要な変更を整理します。

## 実習三：キャッシュの分離を証明

```sh
curl -i http://localhost:3100/docs/en/architecture/
curl -i -H 'If-None-Match: W/"COPY_THE_RETURNED_HASH"' http://localhost:3100/docs/en/architecture/
```

応答で受け取った ETag を使って再度リクエストし、本文のない `304` 応答を確認します。別の言語版や、`SITE_URL` を設定していない状態での別のプレビューホストには、それぞれの canonical URL と ETag が必要です。

## 実習四：アニメーションの回帰を見つける

動きを減らす設定でも最初の画面が表示されることを確認します。初期の opacity のまま止まって内容が見えなくなる原因を説明し、表示領域内にあるか、タブがアクティブか、30fps の上限や DPR がどう影響するかを同じ条件で測定します。

## 実習五：文書移動後の SEO

各言語版の説明文と frontmatter を同期し、記事の移動やアラビア語と英語の切り替え後にメタデータを確認します。前のページのメタデータを取り除く処理と、移動後に不要となった更新を取り消す処理を説明します。

## 実習六：コンポーネントと入力を確認

`capability-demos.tsx`、`use-demo-scene.ts`、`assets.json` を読み、アニメーションの一段階を変更します。一時停止と表示状態による制御を維持し、リソースのファイルが変わった場合にだけハッシュ値を更新します。生成されたチャンクが `/harness-source/` のファイルを要求しないことも確認します。

## 成果の説明

利用者の問題、実装境界、検証と限界を記録します。上流のデモをすべて自作と主張せず、残るモバイルコストと手動レビューも含めます。`pnpm verify`、関連ブラウザーテスト、必要な性能／リンク確認を行い、[アーキテクチャ](../architecture/)へ戻って流れを照合してください。

## 改善を最後まで追跡する

以下のソースから長いタスクを追跡し、小さな変更後に転送量、操作と画像を比較します。レポートは管理対象外に保存します。基準画像の更新前に差分を確認してください。ローカル画像は回帰の参考であり、元サイトとの完全一致の証明ではありません。

```sh
pnpm analyze
pnpm perf:repeat
pnpm test:visual
```

| 用語              | 意味                                           |
| ----------------- | ---------------------------------------------- |
| SSR               | サーバーサイドレンダリング                     |
| Hydration         | ハイドレーション：サーバーの HTML に操作を追加 |
| Reduced motion    | 動きを減らす設定                               |
| RTL               | 右から左へのレイアウト                         |
| Visual regression | ビジュアルリグレッションテスト                 |
| Resource budget   | リソース予算                                   |

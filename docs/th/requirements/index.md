# ข้อกำหนดของเว็บไซต์

ตรวจว่าเนื้อหาอ่านได้เมื่อปิดภาพเคลื่อนไหว ชื่อยาว เมนู และคำสั่งต้องพอดีกับหน้าจอแคบ หลัง Hydration ให้ทดสอบคีย์บอร์ด การพัก การคัดลอก และลิงก์

แต่ละภาษาต้องมีพจนานุกรม การ์ด ป้ายสำหรับเทคโนโลยีช่วยเหลือ เมทาดาทา เมนู คำอธิบาย และบทความห้าบท รักษาตัวแปรและแท็ก rich text ให้ครบ frontmatter ต้องตรงกับ `docs/descriptions.json`

สร้างรุ่น production ก่อนทดสอบเบราว์เซอร์และเลือกพอร์ตที่ว่าง หาสาเหตุของ checksum ที่ผิดก่อนอัปเดตไฟล์อ้างอิง เซิร์ฟเวอร์ต้องมี `public` ครบ ตรวจ `SITE_URL`, ทางเข้าอังกฤษ, 404, sitemap, favicon, ชิ้นส่วนที่โหลดภายหลัง และแคช สำหรับ Pages ต้องตรวจ path prefix ด้วย

ตรวจหน้าจอแคบ RTL ข้อความหลายทิศทาง โฟกัส โปรแกรมอ่านหน้าจอ และการลดการเคลื่อนไหว บันทึกอุปกรณ์และเบราว์เซอร์ที่ใช้ คำแปลยังต้องให้ผู้ใช้ภาษาไทยเป็นภาษาแม่ตรวจทาน

```sh
pnpm verify
E2E_PORT=3101 pnpm test:e2e
pnpm verify:full
SITE_URL=https://example.github.io/repository/ pnpm build:pages
SITE_URL=https://example.github.io/repository/ pnpm check:pages
```

# ภาพรวมโครงการ

คลังโค้ดนี้สร้างเว็บไซต์ DeepSeek Harness ขึ้นใหม่ด้วย Next.js และ React เอกสารอธิบายโครงสร้างหน้า คอมโพเนนต์ ภาษา ภาพเคลื่อนไหว และการทดสอบ โดยใช้ VitePress สร้างบทความ

ผู้เข้าชมทำความรู้จักผลิตภัณฑ์ ดูตัวอย่างทั้งสี่ เปิดรายละเอียด แล้วเลือกทำสิ่งถัดไป เนื้อหาที่เรนเดอร์จากเซิร์ฟเวอร์ ลิงก์จริง และองค์ประกอบ HTML ยังใช้งานได้เมื่อปิด JavaScript

`src/i18n/locales.json` เป็นแหล่งข้อมูลร่วมของภาษา เส้นทาง ทิศทางข้อความ และเมทาดาทา `/harness/` ยังคงเป็นทางเข้าภาษาจีน ส่วน `/docs/` เปิดเอกสารภาษาอังกฤษ ทุกภาษามีห้าบทเหมือนกัน

คอมโพเนนต์ที่อ่านได้ช่วยให้ดูแลต่อได้ง่าย การ build ผ่านเพียงอย่างเดียวไม่ยืนยันความเหมือนของภาพ ความเป็นธรรมชาติของภาษา หรือประสิทธิภาพบนอุปกรณ์จริง

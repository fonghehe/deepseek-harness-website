# เส้นทางการเรียนรู้

เปิดเว็บไซต์แล้วอ่านโค้ดที่สร้างหน้า แบบฝึกหัดหกข้อครอบคลุมการ์ด ภาษา แคช ภาพเคลื่อนไหว เมทาดาทาของบทความ และทรัพยากร

1. ปรับการ์ดในทุกภาษาโดยรักษา ID และลิงก์ เปรียบเทียบ HTML จากเซิร์ฟเวอร์กับ DOM หลัง Hydration
2. ติดตามภาษาตั้งแต่เมนูถึงบทความ `lang`, `dir` และ sitemap การเปลี่ยนภาษาต้องรักษา query และส่วนย่อยของ URL
3. ทดสอบ ETag จริง การตอบ `304` ที่ไม่มีเนื้อหา และการแยกแคชตามภาษาและ origin
4. ตรวจการพัก การอยู่ในหน้าจอ แท็บเบื้องหลัง และการลดการเคลื่อนไหว พร้อมรักษาพฤติกรรมปกติ
5. เปลี่ยนบทความและภาษาแล้วตรวจ canonical ข้อมูลแชร์ และทิศทาง
6. แก้หนึ่งช่วงของฉากแล้วตรวจซอร์ส ไฟล์ต้นทาง และแฮช รุ่น build ต้องไม่ร้องขอ `/harness-source/`

เปรียบเทียบข้อมูล การโต้ตอบ และภาพก่อนเปลี่ยนไฟล์อ้างอิง เก็บรายงานนอกซอร์สที่ติดตามเวอร์ชัน อธิบายปัญหาที่ผู้ใช้พบ โค้ดที่เกี่ยวข้อง ผลทดสอบ และข้อจำกัดของหลักฐาน ภาพในเครื่องไม่ได้ยืนยันความตรงกับต้นฉบับทุกพิกเซล

```sh
pnpm analyze
pnpm perf:repeat
pnpm test:visual
```

| คำศัพท์           | ความหมาย                                         |
| ----------------- | ------------------------------------------------ |
| SSR               | การเรนเดอร์ฝั่งเซิร์ฟเวอร์                       |
| Hydration         | Hydration: เพิ่มการโต้ตอบให้ HTML จากเซิร์ฟเวอร์ |
| Reduced motion    | การตั้งค่าให้ลดการเคลื่อนไหว                     |
| RTL               | รูปแบบการจัดวางจากขวาไปซ้าย                      |
| Visual regression | การทดสอบความเปลี่ยนแปลงของภาพหน้าจอ              |
| Resource budget   | ขีดจำกัดการใช้ทรัพยากร                           |

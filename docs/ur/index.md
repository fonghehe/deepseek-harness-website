# منصوبے کا تعارف

یہ ریپوزٹری Next.js اور React سے DeepSeek Harness ویب سائٹ دوبارہ بناتی ہے۔ دستاویزات میں صفحات کی ساخت، کمپوننٹس، زبانوں، اینیمیشن اور جانچ کے طریقے بیان ہیں۔ مضامین VitePress سے بنتے ہیں۔

قاری پہلے پروڈکٹ سمجھتا ہے، چار ڈیمو دیکھتا ہے، تفصیل کھولتا ہے اور اگلا قدم چنتا ہے۔ سرور کا مواد، حقیقی لنکس اور HTML کی تفصیل JavaScript کے بغیر بھی کارآمد رہتے ہیں۔

`src/i18n/locales.json` زبان، راستوں، تحریر کی سمت اور میٹا ڈیٹا کا مشترکہ ماخذ ہے۔ `/harness/` چینی داخلی راستہ رکھتا ہے؛ `/docs/` انگریزی کھولتا ہے۔ ہر زبان میں وہی پانچ ابواب ہیں۔

قابلِ فہم کمپوننٹس دیکھ بھال آسان بناتے ہیں۔ کامیاب build خودبخود بصری مماثلت، فطری ترجمہ یا حقیقی آلے کی کارکردگی ثابت نہیں کرتا۔ ہر پہلو کی الگ جانچ ضروری ہے۔

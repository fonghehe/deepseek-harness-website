# سیکھنے کا راستہ

ویب سائٹ کھولیں اور صفحہ بنانے والا کوڈ پڑھیں۔ چھ مشقوں میں کارڈز، زبانوں، کیش، اینیمیشن، مضامین کے میٹا ڈیٹا اور وسائل کی جانچ کریں۔

1. ہر زبان میں کارڈ بہتر کریں؛ ID اور لنکس محفوظ رکھیں۔ سرور HTML اور Hydration کے بعد DOM کا موازنہ کریں۔
2. زبان کو مینو، مضمون، `lang`، `dir` اور sitemap تک دیکھیں؛ زبان بدلنے پر query اور URL کا حصہ محفوظ رہے۔
3. حقیقی ETag، خالی `304` اور زبان و origin کے مطابق کیش کی علیحدگی جانچیں۔
4. وقفہ، نظر آنا، پس منظر کا ٹیب اور کم اینیمیشن جانچیں اور عام رویہ محفوظ رکھیں۔
5. مضمون اور زبان بدل کر canonical، شیئر میٹا ڈیٹا اور سمت جانچیں۔
6. منظر کا ایک مرحلہ بدلیں اور سورس، اصل فائل اور ہیش جانچیں۔ build کو `/harness-source/` نہیں مانگنا چاہیے۔

حوالہ بدلنے سے پہلے ڈیٹا، تعامل اور تصویر کا موازنہ کریں۔ رپورٹ کو ورژن والے سورس سے باہر رکھیں۔ قاری کا مسئلہ، متعلقہ کوڈ، ٹیسٹ کا نتیجہ اور ثبوت کی حد بیان کریں۔ مقامی تصویر اصل سائٹ سے ہر پکسل کی مماثلت ثابت نہیں کرتی۔

```sh
pnpm analyze
pnpm perf:repeat
pnpm test:visual
```

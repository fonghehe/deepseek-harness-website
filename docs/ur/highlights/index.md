# فرنٹ اینڈ کے طریقے

## معلومات اور کنٹرول

فائدے سے مثال، تفصیل اور اقدام کی طرف جائیں۔ حقیقی لنکس اور HTML کنٹرول استعمال کریں۔ کی بورڈ، Escape، فوکس کی واپسی، تنگ اسکرین کے مینو اور JavaScript کے بغیر استعمال جانچیں۔

## زبانیں اور SEO

لغت، معاون ٹیکنالوجی کے لیبل، میٹا ڈیٹا، نیویگیشن اور مضمون میں مطابقت ہونی چاہیے۔ RTL میں logical CSS استعمال کریں؛ کوڈ LTR رہے۔ کلائنٹ نیویگیشن کے بعد بھی canonical، hreflang، structured data اور شیئر میٹا ڈیٹا موجودہ صفحے کے مطابق ہوں۔

## وسائل اور ثبوت

کمپوننٹس، shader، CSS، Markdown اور اصل جامد فائلیں براہ راست دیکھ بھال کا حصہ ہیں۔ `tests/fixtures/assets.json` سالمیت جانچتا ہے؛ `.next`، `public/docs` اور رپورٹیں بننے والا آؤٹ پٹ ہیں۔ برانڈ اور لائسنس کی تفصیل `NOTICE.md` میں ہے۔

ڈیٹا کا حجم، LCP، CLS اور بلاکنگ وقت بار بار اور حقیقی آلات پر ناپیں۔ ریگریشن چھپانے کے لیے baseline نہ بدلیں۔ مقامی ٹیسٹ، دور دراز CI اور زبان یا رسائی کی انسانی جانچ الگ ثبوت دیتے ہیں۔

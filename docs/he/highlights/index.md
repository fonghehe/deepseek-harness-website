# בחירות בפרונטאנד

## מידע ושליטה

עברו מתועלת לדוגמה, לפרטים ולפעולה. השתמשו בקישורים אמיתיים וב־HTML טבעי. בדקו מקלדת, Escape, החזרת מיקוד, תפריטים צרים ועבודה ללא JavaScript.

## שפות ו־SEO

מילונים, תוויות נגישות, מטא־נתונים, ניווט ומאמרים חייבים להתאים. RTL דורש מאפייני CSS לוגיים; הקוד נשאר LTR. Canonical, hreflang, נתונים מובנים ומטא־נתוני שיתוף חייבים לתאר את העמוד הנוכחי גם לאחר ניווט בלקוח.

## מקורות וראיות

רכיבים, שיידרים, CSS, Markdown וקלט סטטי הם מקורות מתוחזקים. `tests/fixtures/assets.json` בודק שלמות; `.next`, `public/docs` ודוחות הם תוצרים. מותגים ורישיונות מוסברים ב־`NOTICE.md`.

מדדו שוב ושוב נפח נתונים, LCP, CLS וזמן חסימה, ובדקו מכשירים אמיתיים. אל תשנו baseline כדי להסתיר רגרסיה. בדיקות מקומיות, CI מרוחק וסקירה אנושית של שפה או נגישות מספקים ראיות שונות.

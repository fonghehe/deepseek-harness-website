# מסלול למידה

פתחו את האתר וקראו את הקוד שמרכיב את העמוד. ששת התרגילים עוסקים בכרטיסים, שפות, מטמון, אנימציות, מטא־נתונים של מאמרים ומשאבים.

1. שפרו כרטיס בכל השפות, שימרו ID וקישורים והשוו HTML של השרת ל־DOM אחרי הידרציה.
2. עקבו אחר שפה עד לתפריט, מאמר, `lang`, `dir` ו־sitemap; שימרו query וקטע URL בעת מעבר שפה.
3. השתמשו ב־ETag אמיתי לבדיקת `304` ריק ובידוד מטמון לפי שפה ו־origin.
4. בדקו השהיה, נראות, לשונית רקע והפחתת אנימציה בלי לשנות התנהגות רגילה.
5. החליפו מאמר ושפה ובדקו canonical, נתוני שיתוף וכיוון.
6. שנו שלב אחד בסצנה ובדקו מקור, קלט וחתימות. הבנייה לא צריכה לבקש `/harness-source/`.

השוו נתונים, אינטראקציות ותמונות לפני שינוי ייחוס. שימרו דוחות מחוץ למקורות שבניהול גרסאות. הסבירו את בעיית המבקר, הקוד האחראי, תוצאת הבדיקה ומגבלת הראיה. תמונות מקומיות אינן מוכיחות זהות פיקסלים למקור.

```sh
pnpm analyze
pnpm perf:repeat
pnpm test:visual
```

| מונח              | משמעות                                    |
| ----------------- | ----------------------------------------- |
| SSR               | רינדור בצד השרת                           |
| Hydration         | הידרציה: הוספת אינטראקציות ל־HTML של השרת |
| Reduced motion    | העדפה להפחתת אנימציה                      |
| RTL               | פריסה מימין לשמאל                         |
| Visual regression | בדיקות רגרסיה חזותית                      |
| Resource budget   | תקציב משאבים                              |

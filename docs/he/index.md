# סקירת הפרויקט

המאגר הזה משחזר את אתר DeepSeek Harness באמצעות Next.js ו־React. התיעוד מסביר את מבנה העמודים, הרכיבים, השפות, האנימציות והבדיקות. המאמרים נבנים באמצעות VitePress.

המבקר מכיר את המוצר, רואה ארבע הדגמות, פותח פרטים ובוחר פעולה. תוכן השרת, קישורים אמיתיים ורכיבי HTML נפתחים נשארים שימושיים גם ללא JavaScript.

`src/i18n/locales.json` מרכז שפות, נתיבים, כיוון ומטא־נתונים. `/harness/` שומר על הכניסה בסינית; `/docs/` פותח אנגלית. לכל מהדורת תיעוד אותם חמישה פרקים.

רכיבים קריאים מקלים על תחזוקה. בנייה מוצלחת אינה מוכיחה דיוק חזותי, ניסוח טבעי או ביצועים במכשיר אמיתי; אלה דורשים בדיקות נפרדות.

# 프런트엔드 특징

레이아웃, 컨트롤, 언어, 렌더링의 구현 위치와 확인 방법을 설명합니다.

## 1. 정보 계층

주제, 예시, 상세와 행동이 방문자의 이해 순서를 따릅니다. 애니메이션을 고르기 전에 이 흐름을 설계합니다.

## 2. 작은 확장 경계

기존 데모를 유지하고 공통 JSON과 HTML로 내용을 추가합니다. 페이지 전체 복제로 디자인이 나뉘는 것을 피합니다.

## 3. 브랜드 재사용

검은 favicon, 글꼴, 아이콘과 그림을 로컬에서 제공합니다. 출처와 크기를 검토하며 원본 디자인을 모두 직접 만든 것으로 설명하지 않습니다.

## 4. 다국어 설정의 일원화

언어 등록 정보가 경로, 이름, 방향과 SEO를 연결합니다. 키/변수 검사는 표현과 줄바꿈에 대한 사람의 검토와 함께 사용합니다.

## 5. 동작하는 RTL

논리 CSS, 메뉴 위치와 LTR 코드를 함께 검사합니다. 390px 아랍어 검증은 컨테이너를 뒤집는 것만으로 부족함을 보여 줍니다.

## 6. 점진적 향상

브라우저 기본 접기·펼치기 요소와 실제 링크는 JavaScript 없이 사용 가능합니다. Escape, 외부 클릭, 포커스와 URL 보존을 추가합니다.

## 7. 일관된 하이드레이션

페이지가 언어를 검증하고 사전을 props로 LandingPage에 전달합니다. 서버와 클라이언트는 같은 JSX를 사용합니다. RichText는 허용된 태그만 해석하고 임의 HTML을 주입하지 않습니다. 라우트 그룹의 루트 레이아웃이 서버에서 lang과 dir을 설정합니다.

## 8. 명확한 동작 수명

`use-demo-scene.ts`가 화면 표시, 활성 탭, 동작 줄이기 설정, 일시 정지를 함께 판단합니다. CSS는 재생 위치를 유지합니다. Three.js는 화면 밖에서 멈추고 해제 시 GPU 리소스를 정리합니다. 자세한 내용은 [아키텍처](../architecture/)를 참고하세요.

## 9. 전달과 연결된 SEO

canonical, alternate와 공유 정보를 생성하고 문서 이동 후 갱신합니다. 일반 아랍어에 임의의 지역 OG locale을 만들지 않습니다.

## 10. 올바른 캐시

`website-metadata.ts`는 Next.js Metadata API와 `SITE_URL` 또는 미리보기 요청의 출처를 사용합니다. 아랍어에 임의의 지역 코드를 지정하지 않습니다. VitePress 문서 캐시는 출처와 문서별로 분리하고 최대 128개 항목을 5분 동안 보관합니다. 렌더링에 실패한 항목은 제거하며 약한 ETag가 일치하면 본문 없는 `304` 응답을 반환합니다.

## 11. 리소스 무결성

컴포넌트, Hook, CSS, Markdown, 정적 리소스를 버전 관리합니다. JavaScript와 CSS는 `pnpm build`로 생성하며 `.next`와 `public/docs`는 Git 관리 대상에서 제외합니다. `tests/fixtures/assets.json`을 기준으로 리소스 무결성을 확인하고 캡처한 HTML이나 원본 실행 코드가 다시 포함되는 것을 막습니다.

## 12. 실패에 맞춘 검증

Oxlint, Oxfmt, 번역/리소스 검사, Playwright, axe와 Lighthouse는 다른 속성을 검사합니다. 도구 수보다 실제 실패 경계를 덮는 증거가 중요합니다.

## 남아 있는 과제

컴포넌트 소스를 직접 관리하면 가독성이 좋아지지만 정확한 화면, 모든 상호작용이나 모바일 성능을 증명하지 않습니다. 과거 보고서는 이전 구현입니다. 번역, 포커스와 혼합 방향은 수동 점검이 필요합니다.

## 측정에 기반한 성능

장식 그래픽은 글꼴과 첫 화면 진입 이후 페인트와 유휴 작업을 거쳐 초기화합니다. 영향이 항상 0인 flow-map 분기는 같은 출력을 유지하며 제거했습니다. 프레임 카운터는 명시적 분석에서만 활성화합니다. 화면 밖과 백그라운드 정지, 30fps, 동작 줄이기와 GPU 해제는 유지합니다. Node와 Pages를 따로 측정하고 반복 실험과 실제 기기를 함께 확인합니다.

- `src/components/graphics/schedule-scene.ts`, `fluid-shaders.ts`
- `src/components/graphics/particle-field.tsx`, `tile-scene.ts`
- `tests/tools/audit-performance.mjs`, `tests/fixtures/performance-budgets.json`

# 개요

이 저장소는 Next.js와 React로 DeepSeek Harness 사이트를 재현합니다. 문서에서는 페이지 구조, 컴포넌트, 언어, 애니메이션, 테스트 방법을 설명합니다. 문서는 VitePress로 빌드합니다.

영어가 기본 문서이고 `/docs/`에서 바로 열립니다. 다른 언어판는 같은 5개 장을 보완합니다. 웹사이트의 기존 중국어 진입점 `/harness/`는 별도로 유지됩니다.

## 방문자의 이해를 따라가는 구성

히어로에서 주제와 행동을 제시하고 네 가지 데모로 이해를 돕습니다. 추가 카드는 상세 내용을 펼치고 개발자 영역은 다음 행동으로 연결합니다. 기존 시각적 흐름을 보존하면서 확장하며, JavaScript가 없어도 제목, 링크와 추가 상세 내용은 읽을 수 있습니다.

## 기술별 책임

| 계층            | 역할                          | 소스                     |
| --------------- | ----------------------------- | ------------------------ |
| Next.js         | HTTP, HTML, 리디렉션과 SEO    | `src/app/`               |
| React           | JSX / SSR / hydration         | `src/components/`        |
| 유지보수 코드   | 번역, 확장과 캐시             | `src/lib/`, `src/i18n/`  |
| VitePress / Vue | 정적 문서, 검색과 문서 이동   | `docs/.vitepress/`       |
| 검증            | 타입, 언어, 리소스와 브라우저 | `tests/tools/`, `tests/` |

사이트는 이 저장소에서 관리하는 React 컴포넌트, Hook, CSS로 빌드합니다. Next.js가 서버 렌더링(SSR)과 하이드레이션을 담당합니다. 원본 사이트에서 캡처한 HTML이나 컴파일된 앱을 로드하지 않으며, 브랜드 이미지, 글꼴, 파일 아이콘, WeChat QR 코드 등을 정적 리소스로 사용합니다.

## 장점과 한계

어두운 표면, 글꼴 계층, 여백과 기존 브랜드 리소스가 일관성을 만듭니다. favicon은 검은색입니다. 공통 언어 언어 등록 정보는 경로, 방향과 메타데이터를 연결합니다. 모바일의 렌더링 비용과 애니메이션 유지보수는 지속적인 측정과 검증이 필요합니다. 자동 검증은 번역 품질과 모든 보조 기술을 보장하지 않습니다.

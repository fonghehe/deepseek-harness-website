# ممارسات الواجهة

توضح هذه الملاحظات تنفيذ التخطيط وعناصر التحكم واللغات والعرض، مع الملفات والفحوص المرتبطة بها.

## 1. تسلسل المعلومات

يتبع الموضوع والمثال والتفاصيل والإجراء فهم الزائر. صمم هذه الرحلة قبل اختيار الرسوم المتحركة.

## 2. توسع بحدود صغيرة

تبقى العروض الأصلية ويضيف JSON وHTML المشتركان المحتوى. لا حاجة لنسخة ثانية من الصفحة تقسم التصميم.

## 3. إعادة استخدام الهوية

تقدم الأيقونة السوداء والخطوط والرسوم محليا. راجع المصدر والحجم، ولا تنسب التصميم الأصلي كله إلى هذا المستودع.

## 4. نموذج اللغات المدعومة

يربط سجل واحد المسارات والتسميات والاتجاه وSEO. تكمل فحوص المفاتيح والمتغيرات مراجعة الصياغة والتفاف الأسطر يدويا.

## 5. RTL فعلي

تفحص CSS المنطقية وموضع القائمة وكود LTR معا. تبين العربية بعرض 390px أن قلب الحاوية وحده غير كاف.

## 6. التحسين التدريجي

تعمل عناصر disclosure والروابط الحقيقية دون JS. تضيف Escape والنقر الخارجي والتركيز وحفظ URL تحسينات إلى الأساس الأصلي.

## 7. اتفاق SSR والتهيئة التفاعلية

تتحقق الصفحة من اللغة وتمرر القاموس إلى LandingPage بخصائص props. يستخدم الخادم والعميل JSX نفسه. يفسر RichText الوسوم المسموحة ولا يحقن HTML عشوائيا. تحدد تخطيطات جذور مجموعات المسارات lang وdir على الخادم.

## 8. دورة حياة الحركة

يجمع `use-demo-scene.ts` بين الظهور وحالة التبويب وتقليل الحركة والإيقاف. يحتفظ CSS بموضع التشغيل. يتوقف Three.js خارج الشاشة ويحرر موارد GPU عند إزالة المكون؛ راجع [البنية](../architecture/).

## 9. SEO مرتبط بالتسليم

تُولد روابط canonical وalternate وبيانات المشاركة، ثم تُحدّث بعد الانتقال بين المقالات. لا تعط العربية العامة منطقة Open Graph مخترعة.

## 10. تخزين مؤقت يحافظ على صحة المحتوى

يستخدم `website-metadata.ts` واجهة Metadata في Next.js مع `SITE_URL` أو مصدر طلب المعاينة، دون افتراض منطقة محددة للعربية. تفصل ذاكرة التخزين المؤقت لمقالات VitePress بين المصادر والمقالات، وتحتفظ بما لا يزيد عن 128 إدخالاً لمدة خمس دقائق، وتحذف نتائج العرض الفاشلة. عند تطابق ETag ضعيف، تُرجع استجابة `304` بلا محتوى.

## 11. سلامة الموارد

تُحفظ المكونات وHooks وCSS وMarkdown والموارد الثابتة في نظام التحكم بالإصدارات. يولد `pnpm build` ملفات JavaScript وCSS، ويُستبعد `.next` و`public/docs` من Git. تتحقق الفحوص المستندة إلى `tests/fixtures/assets.json` من سلامة الموارد وتمنع إعادة إدخال HTML ملتقط أو شيفرة تشغيل من الموقع الأصلي.

## 12. فحوص مرتبطة بالإخفاق

تختبر Oxlint وOxfmt وفحوص اللغات والموارد وPlaywright وaxe وLighthouse خصائص مختلفة. قيمة الدليل أهم من عدد الأدوات.

## ما يزال قابلا للتحسين

تحسن ملكية المكونات قابلية القراءة لكنها لا تثبت دقة الصورة أو كل التفاعلات أو أداء الهاتف. تصف التقارير التاريخية التنفيذ السابق. تحتاج الترجمة وتركيز لوحة المفاتيح والنصوص المختلطة الاتجاه إلى مراجعة بشرية.

## أداء قائم على القياس

تبدأ الرسوم الزخرفية بعد جاهزية الخطوط وظهور القسم الأول، ثم بعد الرسم ومهمة خمول. أزيل فرع flow-map ذو التأثير الصفري الثابت مع الحفاظ على النتيجة. لا يُفعّل عداد الإطارات إلا للتحليل الصريح. يبقى الإيقاف خارج الشاشة وفي الخلفية و30fps وتقليل الحركة وتحرير GPU. قِس Node وPages منفصلين وكرر التجارب وافحص أجهزة حقيقية.

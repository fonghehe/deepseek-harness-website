# متطلبات الموقع

استخدم هذه القائمة عند مراجعة تعديل أو التحضير للنشر. اختر الفحوص بحسب الملفات والسلوك الذي تغيّر.

## معايير المراجعة

| المجال        | النتيجة المطلوبة                                        |
| ------------- | ------------------------------------------------------- |
| المعلومات     | فهم الموضوع والإجراء دون مشاهدة كل الحركة               |
| الشاشة الضيقة | التسميات والقوائم والأوامر دون تجاوز أفقي               |
| التفاعل       | روابط بعد التهيئة التفاعلية ولوحة مفاتيح وتفاصيل دون JS |
| اللغات        | عشر نسخ بمسارات واتجاه وبيانات متوافقة                  |
| SEO           | canonical والمشاركة للمقالة الحالية بعد التنقل          |
| HTTP          | عدم خلط الأصل واللغة و304 بلا محتوى                     |

راجع ترتيب القراءة وعلامات الترقيم المختلطة والصياغة يدويا.

## المدخلات التي تحفظ في Git

تُحفظ المكونات وHooks وCSS وMarkdown والموارد الثابتة في نظام التحكم بالإصدارات. يولد `pnpm build` ملفات JavaScript وCSS، ويُستبعد `.next` و`public/docs` من Git. تتحقق الفحوص المستندة إلى `tests/fixtures/assets.json` من سلامة الموارد وتمنع إعادة إدخال HTML ملتقط أو شيفرة تشغيل من الموقع الأصلي.

أما `.next` و`public/docs` والذاكرات والتقارير والحزم المثبتة فهي نواتج. تبقى الإعدادات المشتركة قابلة للنقل والأسرار والإعدادات الشخصية محلية. التجاهل لا يعادل صلاحيات الوصول.

## تحقق التعديل

```sh
pnpm verify
E2E_PORT=3101 pnpm test:e2e
```

ابن الإنتاج أولا واستعمل منفذا خاليا للفحوص المناسبة. طابق الأوصاف وfrontmatter في كل نسخة. افحص سبب اختلاف hash قبل تغيير checksum.

## قبل النشر

ابن الوثائق قبل Next.js وقدم `public` كاملا. تحقق من `SITE_URL` والمدخل الإنجليزي واللغات و404 وsitemap والأيقونة والتحكم بالعروض والحزم الديناميكية. راجع سياسة الذاكرة لكل فئة. النتائج المحلية وCI البعيدة والفحص على المجال المنشور أدلة مستقلة.

## الأداء والصيانة

قارن payload وLCP وCLS والحجب؛ لا يلغي التخزين المؤقت على الخادم تكلفة تنفيذ JavaScript في المتصفح. لا تستبدل baseline لتجاوز فشل، وراجع ميزانية المقالة الموسعة بوضوح. عند تحديث الموارد والحركة، تحقق من المكونات وCSS المرتبطة بها ومصدر الملفات وبصماتها وعدم كسر السلوك السابق.

تابع [مسار التعلم](../learning/).

تعرض الصينية وحدها QR WeChat، وتربط اللغات الأخرى إلى https://x.com/deepseek_ai.

## التحقق اليدوي

افحص لوحة المفاتيح وEscape واستعادة التركيز في القوائم، وإعلان النسخ بقارئ الشاشة. افحص التمرير ومراحل الحركة على هاتف حقيقي. اختبر العناوين الطويلة والأوامر المختلطة الاتجاه بالعربية. سجّل الجهاز والمتصفح وتفضيل الحركة والأدلة. تتطلب الترجمة مراجعة متحدث أصلي.

```sh
pnpm verify:full
SITE_URL=https://example.github.io/repository/ pnpm build:pages
SITE_URL=https://example.github.io/repository/ pnpm check:pages
SITE_URL=https://example.github.io/repository/ pnpm perf:pages
```

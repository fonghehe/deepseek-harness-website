# نظرة عامة

يعيد هذا المستودع إنشاء موقع DeepSeek Harness باستخدام Next.js وReact. تشرح الوثائق بنية الصفحات والمكونات واللغات والحركة وطرق الاختبار. تُبنى المقالات باستخدام VitePress.

الإنجليزية هي النسخة الأساسية ويفتحها `/docs/` مباشرة. وتتبع الترجمات الأخرى البنية نفسها المؤلفة من خمسة فصول. وتبقى النسخة الصينية من الموقع متاحة على مسارها الحالي `/harness/`.

## رحلة الزائر

توضح المقدمة الموضوع والخطوة التالية، ثم تعمق أربعة عروض تفاعلية الفهم، وتكشف البطاقات الإضافية التفاصيل، ويوجه قسم المطور الزائر إلى إجراء عملي. يحافظ التوسع على العروض القديمة ولغتها البصرية. تظل العناوين والروابط والتفاصيل الإضافية مفيدة دون JavaScript.

## مسؤوليات التقنيات

| الطبقة                  | المسؤولية                         | المصدر                   |
| ----------------------- | --------------------------------- | ------------------------ |
| Next.js                 | HTTP وHTML والتحويلات وSEO        | `src/app/`               |
| React                   | JSX / SSR / hydration             | `src/components/`        |
| الشيفرة القابلة للصيانة | الترجمة والتوسع والتخزين المؤقت   | `src/lib/` و`src/i18n/`  |
| VitePress وVue          | المقالات والبحث وتنقل الوثائق     | `docs/.vitepress/`       |
| التحقق                  | الأنواع واللغات والموارد والمتصفح | `tests/tools/` و`tests/` |

يُبنى الموقع من مكونات React وHooks وCSS التي يديرها هذا المستودع. يتولى Next.js العرض على الخادم (SSR) والتهيئة التفاعلية. لا يُحمّل الموقع HTML ملتقطاً أو تطبيقاً مجمعاً من الموقع الأصلي. وتُستخدم صور العلامة والخطوط وأيقونات الملفات ورمز WeChat QR كموارد ثابتة.

## نقاط القوة والحدود

تمنح الأسطح الداكنة وتسلسل الخطوط والمسافات والموارد الموجودة اتساقا بصريا. أيقونة التبويب سوداء. يربط سجل اللغات المسارات والاتجاه والبيانات الوصفية. ما زالت تكلفة العرض على الهاتف وصيانة الحركة تتطلب قياسات وفحوصاً دورية. لا تثبت الفحوص الآلية جودة كل ترجمة أو التوافق مع جميع التقنيات المساعدة.

# ফ্রন্টএন্ডের পদ্ধতি

## তথ্য ও নিয়ন্ত্রণ

উপযোগিতা থেকে উদাহরণ, বিস্তারিত ও পদক্ষেপে যান। প্রকৃত লিংক ও HTML নিয়ন্ত্রণ ব্যবহার করুন। কিবোর্ড, Escape, ফোকাস ফেরত আসা, ছোট পর্দার মেনু ও JavaScript ছাড়া ব্যবহার যাচাই করুন।

## ভাষা ও SEO

অভিধান, সহায়ক প্রযুক্তির লেবেল, মেটাডেটা, নেভিগেশন ও নিবন্ধে মিল থাকতে হবে। RTL-এ logical CSS ব্যবহার করুন; কোড LTR রাখুন। ক্লায়েন্ট নেভিগেশনের পরেও canonical, hreflang, structured data ও শেয়ারের মেটাডেটা বর্তমান পাতার সঙ্গে মিলতে হবে।

## রিসোর্স ও প্রমাণ

কম্পোনেন্ট, shader, CSS, Markdown ও মূল স্থির ফাইল সরাসরি রক্ষণাবেক্ষণ করা হয়। `tests/fixtures/assets.json` অখণ্ডতা পরীক্ষা করে; `.next`, `public/docs` ও রিপোর্ট তৈরি হওয়া আউটপুট। ব্র্যান্ড ও লাইসেন্সের তথ্য `NOTICE.md`-এ আছে।

ডেটার আকার, LCP, CLS ও ব্লকিং সময় বারবার এবং বাস্তব ডিভাইসে মাপুন। রিগ্রেশন আড়াল করতে baseline বদলাবেন না। স্থানীয় পরীক্ষা, দূরবর্তী CI এবং ভাষা বা অ্যাক্সেসিবিলিটির মানব পর্যালোচনা ভিন্ন প্রমাণ দেয়।

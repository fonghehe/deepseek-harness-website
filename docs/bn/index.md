# প্রকল্প পরিচিতি

এই রিপোজিটরি Next.js ও React দিয়ে DeepSeek Harness ওয়েবসাইট পুনর্নির্মাণ করে। ডকুমেন্টেশনে পাতার গঠন, কম্পোনেন্ট, ভাষা, অ্যানিমেশন ও পরীক্ষার পদ্ধতি ব্যাখ্যা করা হয়েছে। নিবন্ধ তৈরি হয় VitePress দিয়ে।

দর্শক প্রথমে পণ্যটি বোঝেন, চারটি ডেমো দেখেন, বিস্তারিত খোলেন এবং পরের পদক্ষেপ বেছে নেন। সার্ভারের কনটেন্ট, প্রকৃত লিংক ও HTML-এর বিবরণ JavaScript ছাড়াও কাজে লাগে।

`src/i18n/locales.json` ভাষা, পথ, লেখার দিক ও মেটাডেটার অভিন্ন উৎস। `/harness/` চীনা প্রবেশপথ রাখে; `/docs/` ইংরেজি খোলে। সব ভাষায় একই পাঁচটি অধ্যায় রয়েছে।

পড়ার উপযোগী কম্পোনেন্ট রক্ষণাবেক্ষণ সহজ করে। build সফল হলেই দৃশ্যের মিল, স্বাভাবিক অনুবাদ বা বাস্তব ডিভাইসের পারফরম্যান্স প্রমাণ হয় না; প্রতিটির আলাদা যাচাই দরকার।

# ওয়েবসাইটের চাহিদা

অ্যানিমেশন বন্ধ করে কনটেন্ট পড়া যায় কি না দেখুন। দীর্ঘ নাম, মেনু ও কমান্ড সরু পর্দায় ধরতে হবে। Hydration-এর পর কিবোর্ড, বিরতি, কপি ও লিংক পরীক্ষা করুন।

প্রতি ভাষায় অভিধান, কার্ড, সহায়ক প্রযুক্তির লেবেল, মেটাডেটা, নেভিগেশন, বিবরণ ও পাঁচটি নিবন্ধ লাগবে। প্লেসহোল্ডার ও rich text ট্যাগ অক্ষত রাখুন। Frontmatter-কে `docs/descriptions.json`-এর সঙ্গে মিলতে হবে।

ব্রাউজার পরীক্ষার আগে production build করুন এবং খালি পোর্ট বেছে নিন। checksum-এর তথ্য হালনাগাদ করার আগে ভুলের কারণ খুঁজুন। সার্ভারে পুরো `public` রাখুন; `SITE_URL`, ইংরেজি প্রবেশপথ, 404, sitemap, favicon, ডায়নামিক অংশ ও ক্যাশ যাচাই করুন। Pages-এ পাথ প্রিফিক্সও পরীক্ষা করুন।

সরু পর্দা, RTL, মিশ্র দিকের লেখা, ফোকাস, স্ক্রিন রিডার ও কম অ্যানিমেশন পরীক্ষা করুন। ডিভাইস ও ব্রাউজার লিখে রাখুন। অনুবাদগুলো বাংলা মাতৃভাষী পাঠকের পর্যালোচনা এখনও প্রয়োজন।

```sh
pnpm verify
E2E_PORT=3101 pnpm test:e2e
pnpm verify:full
SITE_URL=https://example.github.io/repository/ pnpm build:pages
SITE_URL=https://example.github.io/repository/ pnpm check:pages
```

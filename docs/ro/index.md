# Prezentarea proiectului

Acest depozit recreează site-ul DeepSeek Harness cu Next.js și React. Documentația descrie paginile, componentele, limbile, animațiile și testele. Articolele sunt generate cu VitePress.

Vizitatorul descoperă produsul, urmărește patru demonstrații, deschide detaliile și alege un pas următor. Conținutul serverului, linkurile reale și elementele HTML extensibile rămân utile fără JavaScript.

`src/i18n/locales.json` unește limbile, căile, direcția și metadatele. `/harness/` păstrează intrarea chineză; `/docs/` deschide engleza. Fiecare ediție a documentației are aceleași cinci capitole.

Componentele lizibile ajută întreținerea. Un build reușit nu dovedește fidelitatea vizuală, naturalețea traducerii sau performanța pe dispozitive reale; sunt necesare verificări separate.

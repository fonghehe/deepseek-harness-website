# Shared project configuration

Shared editor settings, tasks, extensions and debug configurations live in `.vscode`. See [.vscode/README.md](../.vscode/README.md) for the development workflow.

Shared project rules are versioned. Personal settings, credentials and runtime state remain local.

Repository-root ignore files exclude local secrets, generated output, reports and binary assets from indexing. Indexing exclusions do not replace filesystem permissions.

# Security policy

Security fixes target the current default branch. This repository is a website recreation, not the DeepSeek Harness runtime. Report upstream product vulnerabilities to the upstream maintainers.

For a vulnerability in this website, use GitHub's **Security → Report a vulnerability** when private vulnerability reporting is enabled. Include the affected commit, route, reproduction, impact and a suggested fix if available. Do not put exploits, tokens or private data into public issues. If private reporting is unavailable, open a minimal issue asking the maintainer to establish a private contact, without disclosure details.

Maintainers should enable private vulnerability reporting in repository settings before publication, acknowledge reports and coordinate a fix and disclosure with the reporter. Response time is not guaranteed. Remove leaked credentials from use immediately; a repository deletion alone does not revoke them.

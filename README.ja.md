# DeepSeek Harness Website

[English](README.md) · [简体中文](README.zh-CN.md) · 日本語

**DeepSeek Harness** のサイトを独立して再現したプロジェクトです。デスクトップとモバイルのレイアウト、アニメーションデモ、26 の言語版があります。

デスクトップの作業画面と、プラグイン、ファイル、定期タスク、実行履歴の四つのデモを表示します。アラビア語、ヘブライ語、ペルシャ語、ウルドゥー語は右から左に表示します。技術文書ではサイトの実装とテスト方法を説明しています。

![デスクトップのプレビュー](public/images/showcase-desktop.png)

- **アニメーションデモ**：一時停止と動きを減らす設定に対応。
- **操作**：言語選択、ダウンロード、コマンドのコピー。
- **26の言語版**：英語、中国語（簡体字・繁体字）、日本語、フランス語、ドイツ語、韓国語、ロシア語、アラビア語、スペイン語、ポルトガル語、インドネシア語、トルコ語、ポーランド語、イタリア語、ウクライナ語、ベトナム語、オランダ語、チェコ語、ルーマニア語、ヘブライ語、ペルシャ語、タイ語、ヒンディー語、ベンガル語、ウルドゥー語。
- **技術文書**：構成、実装例、確認項目、ソースコードを使った実習。
